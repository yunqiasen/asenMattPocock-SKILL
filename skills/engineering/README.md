# Engineering Skills

| Skill | 调用方式 | 作用 |
|---|---|---|
| [ask-matt](ask-matt/SKILL.md) | 仅手动 | 不知道使用哪个 Skill 时负责路由 |
| [code-review](code-review/SKILL.md) | 自动 + 手动 | 代码标准轴和规格轴双轴审查 |
| [codebase-design](codebase-design/SKILL.md) | 自动 + 手动 | UI、Deep Module、接口和 Seam 设计 |
| [diagnosing-bugs](diagnosing-bugs/SKILL.md) | 自动 + 手动 | 复现、最小化、假设验证、修复和回归测试 |
| [domain-modeling](domain-modeling/SKILL.md) | 自动 + 手动 | 维护领域词汇、`CONTEXT.md` 和 ADR |
| [grill-with-docs](grill-with-docs/SKILL.md) | 仅手动 | 绑定代码库拷问并维护项目文档 |
| [implement](implement/SKILL.md) | 自动 + 手动 | 按批准的规格或 Ticket 实施，内部运行 TDD 和一次最终审查 |
| [improve-codebase-architecture](improve-codebase-architecture/SKILL.md) | 仅手动 | 扫描架构优化机会并生成 HTML 报告和重构决策 |
| [prototype](prototype/SKILL.md) | 自动 + 手动 | 用可运行原型回答逻辑或 UI 设计问题 |
| [research](research/SKILL.md) | 自动 + 手动 | 基于高可信一手资料调研并生成引用文档 |
| [setup-matt-pocock-skills](setup-matt-pocock-skills/SKILL.md) | 仅手动 | 初始化项目工作流配置 |
| [tdd](tdd/SKILL.md) | 自动 + 手动 | 失败测试、最小实现、重构和提交 |
| [to-spec](to-spec/SKILL.md) | 自动 + 手动 | 对齐结果转正式规格，确认后调用 `to-tickets` |
| [to-tickets](to-tickets/SKILL.md) | 自动 + 手动 | 规格转 Tracer Bullet Ticket，确认后调用 `implement` |
| [wayfinder](wayfinder/SKILL.md) | 仅手动 | 大任务探索地图和调查决策 Ticket |
